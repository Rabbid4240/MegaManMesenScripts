Various Mesen scripts I wrote for NES Mega Man games. This will be updated as time goes on.
To use these, load your game. go to Debug > Script Window > File > Open. Then open the script and press the play button :)
These were tested with the USA versions of each game, but they should work with the JP versions, too. 

MM1Hotswap.lua - Lets you quickly switch weapons (like in MM7) in Mega Man 1
